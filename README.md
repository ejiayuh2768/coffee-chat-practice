# Coffee Chat 练习室

在手机上练英文 coffee chat 的网页 App。用麦克风直接说话，对方（AI 扮演的从业者）会把回复读出来；每个人的背景、性格、说话风格和你认识 Ta 的方式都是随机生成的。聊完给出中文点评，练习记录保存在手机里。

## 怎么用（iPhone）

1. 用 **Safari** 打开 App 的网址。
2. 第一次打开时，在「⚙️ AI 设置」里粘贴 API key，点「保存并测试」。页面里有拿免费 Gemini key 的步骤。
3. 点底部的分享按钮 →「添加到主屏幕」，桌面上就会出现 App 图标。
4. 第一次按「🎤 按一下开始说」时，允许使用麦克风。

对话时顶部有三个按钮：「👤 资料卡」随时看对方的背景，「📜 之前的练习」翻看以前的对话和点评，「⚙︎ 对话设置」切换语音识别方式、通话模式、旁注和朗读。

语音识别有两种方式（在「⚙︎ 对话设置」里切换）：
- **AI 识别**（默认，需要用 Gemini）：录下你说的话，交给 Gemini 结合对话上下文来识别，口音、同音词、人名更准。
- **手机自带识别**：更快；识别完会再让 AI 按上下文修正明显听错的词，修正过的句子下面会显示识别原文。

两种方式都只修正"听错"的地方，不会帮你润色英文，所以点评看到的还是你真实的表达。

麦克风用不了时：「设置 → App → Safari → 麦克风」选允许，并在「设置 → 通用 → 键盘」里打开「启用听写」。如果从主屏幕图标打开时麦克风不工作，就直接在 Safari 里用。

## 在中国大陆使用

- 在「⚙️ AI 设置」里选「**智谱 GLM**」（免费，在 bigmodel.cn 用手机号注册拿 key）或「**DeepSeek**」（很便宜，在 platform.deepseek.com 充值拿 key）。Gemini 和 Claude 在国内连不上。
- 用这两个时，语音识别用 iPhone 自带的听写，AI 再按上下文修正听错的词。
- **出国前（或连得上的时候）先打开一次 App**：App 会把自己存在手机里，之后 github.io 打不开或很慢时，也能从手机里的存档打开。
- Google 字体在国内加载不了，App 会自动改用手机自带字体，不影响使用。

## 隐私

- API key 和练习记录只保存在你自己设备的浏览器里，不会上传到这个仓库或其他地方。
- 聊天内容会发给你选择的 AI 服务（Google Gemini 或 Anthropic Claude）来生成回复。
- 记录在「练习记录」页可以导出成文件备份。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 整个 App（界面、随机人物生成器、语音、AI 调用、记录） |
| `manifest.json` | 添加到主屏幕用的 App 信息 |
| `icon-*.png` | App 图标 |
